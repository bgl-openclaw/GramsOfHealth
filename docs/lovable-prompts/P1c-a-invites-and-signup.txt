RPCs (new or changed)
- invite_client_to_app(p_client_id, p_email?) → { ok, token, email, expires_at, full_name, first_name, practice_name, sender_name, account_exists, message }. Saves p_email to the client if they had no email. Reuses a live link. account_exists = true means this person already has a client login: the SAME link will ask them to sign in and connect.
- client_app_status(p_client_id) → as before, plus invite.account_exists, source, client_status, intake_status, first_name, practice_name, sender_name.
- get_client_invitation(p_token) (works signed out) → { found, valid, reason: 'used' | 'expired' | null, email, full_name, first_name, practice_name, practice_email, account_exists, expires_at }. found = false → not a client invite: fall back to the existing staff invite lookup (lookupInvitation / get_invitation), unchanged.
- claim_client_invite(p_token) (signed in) → { ok, message }. Connects the signed-in client account to the invited client file (if they had their own sign-up file, it is folded into the dietitian's one).
- client_signup_queue() (dietitians/admins; everyone else gets []) → [{ client_id, full_name, email, phone, source, client_status, created_at, has_account, intake_status, submitted_at, matches: [{ client_id, full_name, email, has_account, reasons: ('same email' | 'same phone' | 'same name')[] }] }].
- merge_client_into(p_from, p_into) → { ok, message, client_id }. p_from must be a self sign-up nobody has done dietitian work on; its login, food needs, supplements, weights, goal and answers move into p_into, then p_from is deleted.
- link_client_account / unlink_client_account / client_app_signups are unchanged (now only needed after an unlink).
